# i3system MES · 생산 대시보드 (프론트엔드)

적외선 영상센서(IR Image Sensor) 조립/검사 라인용 MES 대시보드 화면입니다.
React 19 + Vite 기반이며, 차트/게이지는 외부 라이브러리 없이 SVG로 직접 그렸습니다.

## 실행

```bash
npm install
npm run dev       # 개발 서버
npm run build     # 프로덕션 빌드 (dist/)
npm run preview   # 빌드 결과 미리보기
npm run lint
```

## 라인 구성 (i3system 제품 기준)

| 라인 | 제품군 | 대표 품목 | 공정 |
| --- | --- | --- | --- |
| Line 1 | 냉각형 MWIR | Super MARKOS SL (T2SL 1280×1024 / 10㎛) | In 범프 플립칩 본딩 · 디워 진공 실링 |
| Line 2 | 비냉각형 LWIR | TE-EQ2 코어 (µ-Bolometer 640×480 / 12㎛) | 웨이퍼 레벨 진공 패키징 · 코어 조립 |
| Line 3 | InGaAs SWIR | InGaAs 1280 (1280×1024 / 10㎛) | 블랙바디 NUC 캘리브레이션 · 결함화소 검사 |

설비는 인듐 범프 플립칩 본더(FCB) · 웨이퍼 레벨 진공 패키징(WLP) · 헬륨 리크 테스터(HLD) ·
스털링 쿨러 조립기(SCL) · 블랙바디 캘리브레이터(NUC) · 결함화소/NETD 검사기(AOI) 6종이며,
불량 유형도 결함화소 초과 · 진공도 저하 · 범프 접합 불량 · NETD 규격 미달 등 검출기 공정
기준으로 구성했다.

## 디자인 규칙

- **토큰 기반**: 색·반경·그림자·타이포는 모두 `src/index.css`의 CSS 변수. 브랜드 컬러는
  i3system 로고에서 추출한 `#006cb8`이며, 테마는 라이트 단일(다크 모드 없음)이다.
- **상태 색은 단독으로 쓰지 않는다**: 정상/점검요/정지 등은 항상 아이콘 + 라벨과 함께
  표시해 색각 이상·흑백 출력에서도 구분된다 (`StatusChip`).
- **차트는 단일 시리즈**: 일간 추이는 완료수량 한 계열 + 목표 기준선이라 범례가 필요 없고,
  값은 축·툴팁이 담당한다. 막대는 최대 24px, 데이터 끝만 4px 라운드.
- **미터의 색 위계**: 생산개수만 브랜드 컬러, 불량개수는 관리한계(3%/5%)에 따른 상태 색,
  잔여수량·시간경과는 중립색이라 카드에서 한 지표만 주목된다.
- **반응형**: 1440px 미만에서 로트 관리 표가 한 줄을 통째로 쓰고, 1280px 미만에서
  라인/추이 카드가 2열 → 1열로 접힌다. 원본 시안처럼 Line 3이 잘리지 않는다.

## 데이터 연동

지금은 `src/data/mockData.js`의 목업 데이터를 쓰고, `App.jsx`의 `useLiveLines`가 4초마다
가동 라인 실적을 조금씩 올려 실시간 갱신을 흉내낸다. 실제 연동 시에는

1. `mockData.js`의 `lines` / `lots` / `dailyTrend` / `equipment` / `defectTypes` 형태를
   그대로 반환하는 API를 붙이고,
2. `useLiveLines`를 폴링 또는 WebSocket 구독으로 교체하면 된다.

컴포넌트는 모두 props만 받는 표시 전용이라 데이터 소스 교체에 영향을 받지 않는다.
